# Zaya.DocumentScanner

Scans or photographs paper documents and exports them to PDF/DOCX, reusing the OCR and plugin
infrastructure from the [Zaya](https://github.com/shtrasser-dev) ecosystem
(`Zaya.OCR`, `Zaya.Primitives`, `Zaya.PluginManager`, `Zaya.UI`) instead of a bespoke pipeline.

Early scaffold — no scanning or export functionality yet.

## Get Started

```bash
dotnet build Zaya.DocumentScanner.sln
```
